# Tracks Simulate 重建版

当前运行基线为 **0.6.0-rebuild.24 原交付 JAR**。rebuild.25–27 接触路线已停止；工作区保留冻结的 .27 源码供分析，**未声称源码已回退到 .24**。默认启动入口使用独立 .24 运行目录及存档副本，不构建当前源码。最终目标仍是 Gearwork 的配置/效率、B n T 的自由构型以及可与实体/CBC交互的逐板履带。

本轮提供完整操作链：直接放轮 → Create 传送带按顺序选轮和预览 → 闭合生成 → 接动力/整组调参 → 保存重进 → 拆带/拆轮返还。原先自动扫描相邻一排轮子的建带方式已退出运行路径；已有轮子保留，需要用传送带重新连接。

**rebuild.24 已获用户测试通过；本轮扩大到完整地形接触功能块。** 固定驱动轮/托带轮与带面接触加入统一求解，负重轮保留悬挂。可对地形和其它 Sable 方块支撑、驱动及施加反作用；普通实体、两个自定义履带壳体互撞、损坏维修和 CBC 尚未完成。多人与结构复制仍未完整验收。

## 完整操作

1. 取出驱动轮、悬挂负重轮、托带轮、Create 传送带和悬挂调节棒。新轮子通过 GUI 连续调整尺寸，直接放置，无需 Shaft 或车架。
2. 将轮子放在同一轮轴平面，允许间隔及不同高度。手持传送带按周向顺序右键各轮，再右键第一个轮闭合。玩家决定顺序，自动决定绕行方向。选中轮为黄色框，路径为绿色；无效/交叉预览为红色，服务端拒绝生成并说明原因。
3. 潜行右键撤销末点；换槽、换手、丢弃、打开界面、对空气使用会取消未完成选点。临时选点不写入物品或存档。当前预算 64 节点、相邻选点 64 格、选点范围 128 格、总带长 512 格；完全重心重合/包含而无切线的轮对尚未支持。
4. 生存模式每条闭环消耗一个 Create 传送带。闭环生成后，非相邻的所选轮子也属于同组。手持传送带潜行右键任意成员可拆带；按拆除时的模式处理：生存拆带/拆轮返还一个传送带，即使该带原先在创造模式创建；创造拆除不返还。每条带的移除只能返还一次。
5. 驱动轮 GUI 轴模式：0 左半轴（安装背面）、1 全轴、2 右半轴（轮子正面）、3 无轴。左右随安装朝向；不切换模型。连接履带后的所有驱动轮接入 Create 同一动力网络，轴端 1:1 传动，共享应力与过载，由 Create 处理冲突。无轴关闭本轮外部接口，仍可随履带转动。驱动轮默认位于方块中心，可手动偏移但没有悬挂伸缩；负重轮保持独立悬挂。
6. 调节棒右键或对准轮子按 J 打开 GUI。大小按默认尺寸倍率输入（0.25–5×），1× 恢复该轮默认尺寸，轮心不变；保留旧轮实际大小。下方统一选择“当前轮／同类轮／整组轮”，默认当前轮。回车/应用与加减提交单项，“同步当前配置”提交全部有效输入（含草稿），全部遵守所选范围。已连接同类/整组限当前履带环；未连接只提供当前轮/同类轮，同类限 8 格内、同一 Sable 子结构、未连接且已加载的同种轮（最多 64 个）。不支持的参数跳过。宽度也按所选范围修改，不同宽度的带面渐变衔接。驱动轮与负重轮均可独立偏移，保留斜向连接。尺寸/偏移批次校验失败时全部拒绝并保留输入。染色仍是独立整环交互。改变轴向需先拆带重连。
7. 保存退出、重进检查轮组与调参。Create 扳手潜行右键返还轮子；拆掉成员会拆除所属带并在生存拆除时返还一次。旋转拆解、结构复制、跨维度迁移尚未完整验收，不以普通保存重进代表它们已通过。

## rebuild.25 地形接触、支撑与驱动

轮体及带面内外侧、左右侧都参与有限接触采样；驱动轮保持固定轮心，托带轮没有额外悬挂。负重轮的原悬挂承载区域排除重复刚性支撑。固定轮和带面可直接承载、带动被动环滚动或按照主动带速产生牵引，并处理与其它 Sable 方块的反作用。固定轮现在也能配置纵横摩擦和驱动力响应，遵守原 GUI 同步范围。

目标线速度统一为输入 RPM × 轮周长 / 60（含原转速倍率与绕向）；驱动力增益调节追随目标的响应，不另外增加转速。相对旧版的经验推力换算，实际行驶速度可能变化，需要回归原车双流转向及制动。

服务器参数 `surfaceProbesPerLoop=512`、`surfaceContactsPerBody=64` 分别限制每环每游戏 tick 的新增表面采样和每车每物理子步的新增合并接触；原悬挂五射线仍单独运行。有限采样不等于无遗漏的连续碰撞，也不保证长带、薄障碍及高速场景完全覆盖。`TS-SURFACE` 在后台物理日志中报告覆盖和耗时。

本轮测试包括：驱动轮单独承载、轮间带面跨障碍承载、侧面与翻转接触、主动/被动运动、零摩擦与制动、活动物理载荷及原车回归。清单见本地 `docs/TEST_REBUILD25_2026-10-18.md`。客户端与服务端使用相同 rebuild.25，包格式仍为 1.14.0；我没有运行游戏。

## rebuild.24 被动闭环与共享带面

一条已连接的履带没有任何驱动轮时，由服务端求解共享滚动速度。负重轮接地摩擦带动整环，所有成员按绕向和半径同步转动；纵向摩擦为零时不会凭车体位移假装滚动，已有转动则保留惯性。任意成员上方红石 15 锁止整环，较低信号提供部分制动。有驱动轮的环保持原有 Create 动力行为；电机转速为零不等于没有驱动轮。

采用整环一个等效滚动惯量，不创建履带板刚体。服务器配置 `passiveRollingMassPerWheel` 默认每个选中轮 1 kg 的等效滚动质量，仅用于滚动惯量，不增加车体质量；这不是最终单片履带的物性定义。普通静止世界上的方块不会因有带纹就自行转动；尚无负重轮接触的带面要等 M3。

客户端/服务端均使用 rebuild.24（协议 1.14.0）。整环运动以根节点轻量包同步，保存材料位移；加载后由当前接触重新建立滚动速度。`TS-MOTION` 写入后台物理日志。手持调节棒打开已连接轮 GUI 时，`TS-GEOMETRY` 记录服务端带面查询结果。

绘制和有限射线查询使用同一带面壳体、厚度、宽度和段身份；查询接口不会自动让 Sable、普通实体或 CBC 碰到履带。全周接触、损坏和炮弹仍属后续阶段。本轮实际游戏效果待用户验证，清单见本地 `docs/TEST_REBUILD24_2026-10-18.md`。

## rebuild.22 行程与摩擦语义

最大伸长 E 从偏移点向下量取；最大压缩 C 从全伸长位置向上缩短。以 D=-垂直偏移表示向下偏移，实际向下范围为 `[D+E-C,D+E]`，允许 `C>E`，要求 `0≤C≤D+E`。多项联动修改后按同步一次提交；非法批量配置整次拒绝。

触底止挡独立于弹簧冲量上限，仍使用当前地形采样与有限迭代求解；不是完整带面碰撞。纵向摩擦增大提高牵引/制动额度，侧向增大增强抗侧滑并增加转向阻力。任一轴为 0 时，该方向的履带摩擦冲量为 0。旧存档会转换压缩语义，并记录范围修复。

客户端/服务端使用 rebuild.22，协议 1.13.0。本地验收清单：docs/TEST_REBUILD22_2026-10-17.md。以下为历史版本记录；rebuild.21 的旧行程和共享止挡预算定义已经取代。

## rebuild.20 四态轴与动力网络

已读取本机 Create RotationPropagator / KineticBlockEntity，并核对安装的 6.0.10 二进制：使用其自定义邻接与传动比接口组网，未复制转速、应力或另写冲突判定。Create 可因反向冲突、超速或不一致的传动闭环拆掉连接组件；同向不同速不强行判作冲突，保留 Create 原行为。

四态轴兼容旧半轴/全轴存档。建立、拆带、拆轮、批量轴模式切换及已加载成员变化按旧图断开、新图重连处理；不扫描其它子结构、不主动加载区块。网络仅连接当前履带内同车体的驱动轮，保留 64 节点上限。`TS-KINETIC` 每五秒输出已加载驱动轮的网络 ID、理论/有效转速、应力、容量、来源及过载状态，重建另有事件日志。

1:1 指 Create 轴端转速；尺寸/履带速度倍率不改变外接轴比。带体速度倍率仍由选点顺序中首个有效驱动轮解释，既有外观/物理语义保留，不把各轮倍率叠加。应力保持每驱动轮基础 16 的原有规则，由 Create 根据 RPM 计入网络；不新增车重到动力应力的模型。

双方使用 rebuild.20，协议 1.11.0。本地测试清单 `docs/TEST_REBUILD20_2026-10-16.md`。后续版本小节为历史记录。

## rebuild.16 倍率与显式同步

本轮为 M2 配置功能块修订，未宣布 M2 整体完成。GUI 移除原“从附近轮拉取”和分裂的范围按钮，统一推送当前输入；服务端校验权限、距离、环标记、子结构、加载状态和有限目标。带尺寸/偏移的批量操作先校验最终几何，再统一提交；只改物理参数不重算绕向。每轮仅一次配置更新。服务器明确回执，拒绝保留草稿。

旧存档实际半径保持，界面换算成默认尺寸倍率；各轮默认尺寸仍按现有轮种/旧尺寸注册，不将所有类型强制设为同一直径。宽度不再在建带时自动统一。悬挂支杆隐藏进入数值配置（0/1），遵守同一范围；它不是隐藏整个轮子。

双方须使用 rebuild.16（协议 1.7.0）。离线构建、生产策略/几何检查已通过，尚待玩家测试。清单：`docs/TEST_REBUILD16_2026-10-15.md`。后续版本记录均为历史行为，以本节及上方操作说明为准。

## rebuild.14 连续尺寸与托带轮

- 创造栏和新合成只保留负重轮、驱动轮、托带轮三类。旧小/中/大方块注册、掉落和默认尺寸保留，旧车不必拆换；旧尺寸升级配方退出，新建通过 GUI 调节。
- 调试棒 GUI 可输入半径 **0.25–2 格**（直径 0.5–4 格）与宽度 **0.25–3 格**，按钮步长 0.05。轮径默认本轮，可独立切换同类/整组；宽度始终应用整组。偏移范围不受轮径范围按钮影响。
- 闭合建带明确采用首选轮的宽度统一全组，其它参数不自动复制。手动同步同类轮包含半径；未连带时也复制宽度，已连带保持组宽。无效尺寸/偏移会在变更前拒绝。
- 托带轮使用用户模型，固定在可调安装点，参与选点、相切绕行和随带旋转，不提供悬挂支撑或动力。驱动轮仍固定，负重轮仍独立悬挂。
- 轮径同时用于外观、路径、转速比和轮下采样；宽度影响轮体/带体及轴向采样范围。每个负重轮固定五次查询、至多一份支撑。仍不是全周带面碰撞。
- 双端统一使用 rebuild.14（网络协议 1.5.0）。本机完整测试流程：`docs/TEST_REBUILD14_2026-10-14.md`。M2 尚未整体验收。

## rebuild.13 闭环自动绕向

- 自动规划改为完整闭环核算真实相邻三轮。根据玩家有序轮廓的凸/凹转向约束绕行侧，直线轮排避免无理由翻侧，再比较局部交叉和连接/包绕偏好。三角形与其它凸形轮排不会因评分偏好而整排绕到带外；有意的凹形导向仍可反向绕行，不按轮子角色强制“下绕”。
- 内部规范首点和遍历方向，结果映射回玩家原轮序；换首点或反向选同一个环不应改变其物理外形。预览、创建及手动配置重算共用核心。悬挂运动不重新选择绕向。
- 旧轮组完整加载后升级一次绕行数据版本，不改参数、不换装配 ID、不增减传送带。无合法结果时保留旧数据并记录原因，避免反复重算。客户端和服务端都需使用本版。
- 本轮覆盖日志实例及其同类几何回归；游戏、复杂大行程 PATH-002 和承载稳定性仍待验收。

## rebuild.12 补轮同步与绕行配置

- 生存拆带/挖轮/扳手拆轮均按拆除时模式返还传送带，创建时模式不再阻止手动生存返还。背包满时掉落在玩家旁。
- GUI 新增“从轮组同步”：换轮后可先在新轮上点击，再重新连带。未连接时从同车体、同安装平面且同朝向的 16 格范围内查找；已连接时只从所属轮组查找。优先同类、再优先已配置轮，附近来源按距离排序，结果显示相对位置。仅复制到当前轮；同类也复制偏移和悬挂显示，不同类保留本轮偏移。
- 建带以安装位置（包含显式偏移、不含瞬时悬挂行程）决定绕向，再以当前轮心绘制。手动同步或调整偏移会重新校验并保存绕向；悬挂运行不反复改选侧。无法形成有效安装路径的修改会拒绝，并在 GUI 显示原因。
- 放置和连带不会自动复制参数，也没有原位置记忆。明确点击同步才覆盖当前轮及界面未提交草稿。
- 三个位置参数支持本轮、同类轮、整组。旧驱动轮以前存下但未生效的偏移在升级时归零，旧负重轮实际偏移保留。驱动轮可显式设置安装偏移，但不会获得悬挂。

## rebuild.10 保留的消失问题说明与检查范围

用户最新日志记录 `maxArcDegrees=359.99`、`valid=false`、`meshSpans=0`。原因是浅凹姿态把近零包角展开成额外整圈，触发自交后渲染清空整环。

现在相邻有限规划线在轮外相交时裁掉多余绕圈，保留其规划交点；真实轮缘连接仍为切线/圆弧。悬挂不会重新选择已经保存的绕行侧。运行时异常保留可计算的当前区段并记录，不再因自交判定直接清空整环。内外带面与侧封口提供 0.07 格视觉厚度。

这项修复不等于所有大行程外形已符合目标。高低交错样本仍有超过半圈的包绕，作为 PATH-002 保留；本轮不要求用户重复证明该已知问题。游戏中的消失问题仍需同车回归确认。

`build` 包含真实几何核心检查，不启动游戏。已做离线构建、资源及 Sable 2.0.0/2.0.5 接口检查；未运行游戏或伪造驾驶/性能结果。
