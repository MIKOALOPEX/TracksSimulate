# Tracks Simulate

基于 Minecraft 1.21.1、Create 和 Sable 的可配置履带模组。当前源码版本：**`0.6.0-rebuild.24-restored`**，网络协议 **1.14.0**。

## 当前状态

项目已从旧 prototype 重建。rebuild.24 原包获得项目所有者的游戏测试认可；随后 rebuild.25–27 的接触方案未通过，现已撤销，后续直接从 .24 开始。

没有 .24 历史源码快照，变动部分依据核验过的原 .24 JAR 恢复。恢复包和原包的 107 个 class 清单一致，其中 92 个字节一致；同一工具重新反编译后的全部 Java 输出一致。资源仅版本标识不同。恢复源码通过了构建和离线检查，**恢复包尚未单独进行游戏验收**，不冒称原包的字节级复原。

### 已实现

- 驱动轮、悬挂负重轮、托带轮直接放置；玩家按顺序选轮，自动决定绕行方向，预览后闭合建带。
- 驱动轮固定安装中心，可手动偏移；负重轮独立悬挂。连续尺寸倍率、宽度、偏移及隐藏配置。
- 调试 GUI 手动输入、步进、悬停说明；当前轮、同类轮、整组轮的有界配置同步。
- 四态轴接口：左半轴、全轴、右半轴、无轴；环内驱动轮接入 Create 动力网络，由 Create 处理应力、过载及输入冲突。
- 悬挂伸长/压缩限位、独立纵向和侧向摩擦、驱动转速倍率；无驱动轮闭环的被动滚动与红石制动。
- Copycat 材质填入、取回、保存；带厚与侧封面；生存拆带/拆轮返还。
- 带体绘制与有限射线查询共用几何；运动同步及有界后台诊断日志。

### 尚未实现或未验收

当前承载依赖负重轮接地和悬挂。**固定驱动轮、托带轮及轮间带体没有新增的全周承载能力**。共享带面查询不等于已注册物理碰撞。

逐片机械履带、轮间无轮带段的真实传力、整圈接触与驱动、普通实体交互、损坏维修和 CBC 炮弹交互尚未完成。多人、结构复制、跨维度及大规模定量性能验证尚未完整验收。

最终目标：Gearwork 的配置能力与效率、BnT 的选点和自由构型，以及可与实体/炮弹交互的履带。下一阶段先验证完整的“地面→履带板及连接→轮→悬挂/轮轴→车体”传力链，不继续 .25–27 的带面直接顶车方案。

## 构建

需要 **JDK 21**；Gradle Wrapper 为 9.2.1，NeoForge 为 21.1.248。首次构建需要联网下载 Gradle、Minecraft 与构建依赖；离线构建要求已有完整缓存。

将以下**完整原始发行 JAR** 放入项目根目录的 `libs/`，文件名须一致：

| 文件 | 用途 |
|---|---|
| `create-6.0.10.jar` | Create |
| `sable-2.0.5.jar` | 默认 Sable 版本 |
| `create-aeronautics-bundled-1.21.1-1.3.0.jar` | 完整整合包，包含 Aeronautics、Simulated、Offroad |

文件校验值见 [dependency-lock.json](dependency-lock.json)。可选 `sable-2.0.0.jar` 用于 `-PsableVersion=2.0.0` 检查；其接口检查通过不等于游戏兼容已验收。

```powershell
# 在项目根目录执行；JAVA_HOME 指向自己的 JDK 21
./gradlew.bat build --console=plain
# 已有完整缓存时
./gradlew.bat build --offline --console=plain --no-configuration-cache
```

产物：`build/libs/trackssimulate-0.6.0-rebuild.24-restored.jar`。`build` 包含几何、配置、悬挂、被动滚动、共享带面及日志设施检查，不启动游戏。

**不得拆出整合包中的部分子模组部署，也不要再安装独立 Simulated/Offroad。** `build/compile-support/` 是供 Java 编译器访问全部内嵌类的可再生缓存，不能放进游戏 `mods/`。项目要求见 [AGENTS.md](AGENTS.md)。

## 运行与操作

```powershell
./gradlew.bat runClient
# 专服由测试者按需运行并自行处理 EULA
./gradlew.bat runServer
```

默认客户端目录为 `test-environment/rebuilt-2.0.5/`，服务端为 `test-environment/server-2.0.5/`。Gradle 自动准备上述完整模组包并加载本项目源码，**不要额外把本项目 JAR 放入开发运行目录的 mods/**。普通整合包测试需构建 JAR 和匹配依赖，客户端/服务端同版，不混入原版 Tracks 或旧 TracksSimulate。

1. 放置轮子，手持 Create 传送带按周向选轮，再点首轮闭合；潜行右键撤销末点。
2. 调节棒右键轮子或对准轮子按 J 打开配置。尺寸按默认大小倍率变化，缩放不移动中心。
3. 当前轮只改本轮；已连接同类/整组只在当前环内操作。未连接同类限同一 Sable 子结构、8 格内、已加载的同类未连接轮，最多 64 个；未连接没有整组选项。
4. 生存拆带或拆除环内轮子返还一次 Create 传送带；Create 扳手潜行拆轮。普通方块填入可接受的 Copycat 材质，普通扳手取回材质。
5. 车辆物理运行需装配为 Sable 子结构；静态世界中的轮子显示不代表车辆已启用物理。

已完成建带后，手持传送带潜行右键可拆带。当前上限：64 个选中节点、相邻节点 64 格、距首点 128 格、总带长 512 格；并非任意重合/包含的轮布局均有有效切线。

最大伸长 E 从偏移点向下量取；最大压缩 C 从全伸长位置向上缩短。向下偏移 D 等于 GUI 垂直偏移取负，实际向下范围为 `[D+E-C, D+E]`，要求 `0≤C≤D+E`，允许 C 大于 E。纵/侧摩擦均允许为 0，但不关闭 Sable 或其它方块的物理作用。
