# 0.5.9 调试棒、履带返还与明暗修正

## 操作

- 履带调试棒：创造物品栏本模组分类中取得，或木棍 + 红石粉无序合成。物品 ID 为 `trackssimulate:track_debug_stick`，暂用烈焰棒图标。
- 手持调试棒，对轮子原安装点使用，打开轮组调试 GUI。悬挂、尺寸/偏移、显示/轴、履带、状态五个入口统一放在顶部；履带页继续提供全部摩擦、动力、接触参数及蓝色判定框开关。隐藏轮体后仍可点击安装点。
- 导轮半轴/全轴及半轴输入方向在“显示/轴”页保存。半轴正向：X 东、Y 上、Z 南。状态页实时显示转速、轮径、轮心下降、轮子及履带状态。
- 保存时必须仍持调试棒，并通过原有距离、编辑权限和整环一致性检查。旧扳手 GUI 入口移除。
- Create 扳手普通使用取回填充材质；Shift + 使用执行 Create 自带拆除流程，保留其拆除事件和生存轮子返还行为。
- 手持 Create 传送带，未处于选点过程时 Shift + 使用拆除整环，返还 1 条 Create 传送带到背包，生存背包装不下时掉落。创造模式也执行返还。正在选点时仍为撤销末点。
- 直接挖掉、扳手拆掉等方式移除轮子使整环失效时，解除整环并掉落 1 条传送带；其余轮子留在原处。整环只有 1 条返还，不按轮数返还。

## 生命周期及日志

`BeltLifecycle` 在清除成员前登记失效 UUID，存于主世界 `data/trackssimulate_broken_belts.dat`。已加载成员立即解绑；其余成员再次加载时清除旧连接，不重复掉落。记录保留以覆盖跨维度搬移和长期未加载成员，每个失效环一条 UUID，不记录逐帧数据。新连接使用新 UUID。

`moving=true` 的轮子迁移以及区块卸载不触发拆轮掉落。已对照本地 Sable 装配代码：搬移方块使用 moving=true；未启动游戏测试装配行为。旧存档中成员已缺失的结构也会在检测到缺失时返还一次。

返还事件写入 `test-environment/combined/logs/latest.log`，搜索 `belt_removed`，包含 loop UUID、reason（manual/wheel_removed/missing_root/missing_member）、维度、位置、成员数及返还去向。现有独立物理日志继续输出，不改变求解模型。

## 颜色

履带外表面、内表面和两个侧面改用各自几何朝向的明确法线，消除按顶点顺序推导造成的法线翻转；光照采样位置由轮组坐标确定，不再取决于玩家先选择哪个轮子。保留环境光照和正常朝向阴影，不改成全亮材质。用户提供的 belt.png 原样保留。

## 验证与实测

离线 `build prepareClientRun -PtestProfile=combined` 已通过；原有几何、悬挂、接触计算检查通过。新增 60 项法线检查覆盖 X/Y/Z 轮轴、斜段、反向连接及实际闭环四个起点的重排。它们验证计算一致性，不代替游戏画面及库存验收。

请从 `D:\CreateAdd\Start_TracksSimulate_Client.bat` 启动，重点检查：

1. 调试棒各页可读、保存参数生效，判定框可开关；半轴切换输入方向有效。
2. 生存模式扳手潜行拆除首轮/中间轮：轮子返还，整环仅掉落 1 条传送带，填充材质不丢失。
3. 手动拆带保留轮子且返还 1 条；背包满时落地；未完成的选点仍只撤销末点。
4. 卸载重载、退出重进后不重复掉落；装配/拆解车体不误拆履带。
5. 同一轮组换首选轮、正反顺序连接后，对照同一观察位置的带面明暗。已有连接无需重建即可使用新法线。

未启动客户端或服务器，也未修改测试存档。
