# 0.5.8：三角形履带外侧导轮与新贴图

2026-10-05。对应用户报告：三角形履带把外侧导轮留在包围环外，负重轮位置变化后又恢复；履带纹理方向需直接使用新图修正。

## 定位与修复

只读检查了测试世界的 Sable 存档，确认保存的三角形连接包含左右导轮、五个负重轮和顶端托带轮，导轮没有从成员列表删除。该存档已是调整后的状态，不能用它直接还原第一张截图的全部参数。

独立几何复现发现，旧规划器追求短路径并避开自交，却没有保证外侧导轮处于包围环内。例如左右导轮半径 0.45，位置 (0,0)、(5.5,0)，五个半径 0.61772 的负重轮位于 (1..5,-1)，顶端托带轮位于 (4,2)：旧算法选择右导轮反包覆，路径不交叉，但其轮心在环外。抬高负重轮后，下部承托规则又把导轮方向约束到正常方向。这重现了用户描述的错误类型和变化机制，不是对截图尺寸的精确测量。

现在在每次建立承托布局时识别处于整组外边界、且按玩家连接顺序构成凸拐角的**导轮**，将其包覆方向约束为闭环向外绕行。只约束方向，不改变选点顺序、不删导轮，也不把任意异形路径整体替换为凸包。

- 新建连接、预览、读取保存方向、悬挂形变和物理带段使用同一规则。
- 保存过的错误外侧导轮方向会在路径加载时校正，无需拆带重连。
- 内部导轮仍允许反包覆；托带轮的特殊绕带提示和内部凹形路径保持原有规则。
- 负重轮仍仅在实际触及下部带面时提供承托，不恢复中间负重轮把带面拉到上方的问题。
