# 0.5.11 履带长度上限翻倍

- 整环总长：128 → 256 格（包含直段和绕轮弧段，不是车体长度）。
- 相邻轮心距离：32 → 64 格。
- 相对首轮的选点半径：64 → 128 格。
- 渲染点容量：2048 → 4096；物理带段容量：768 → 1536。
- 轮数上限保持 32；物理采样精度、驱动参数和现有碰撞查询安全预算不变。

已有短履带无需重新连接。复杂长履带仍可能触发原有碰撞查询/接触数量保护；本次没有实施性能优化或取消这些保护。

验证涵盖 64 格相邻跨度、超过原 128 格总长、接近 256 格闭环的双向规划与存档路径恢复、完整物理带段，以及超过新上限时的拒绝。游戏中的长车承载和性能由玩家实测，助手不启动测试环境。

对外包：dist/share-0.5.11/trackssimulate-0.5.11-prototype.jar。安装依赖与 0.5.10 相同；只含本模组，不捆绑参考模组。
