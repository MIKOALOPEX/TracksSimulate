- 模型的 `belt`、`rx` 区域维持用户指定的固定纹理；整个连续履带改用新 `belt.png`。
- 导轮和负重轮的基础物理尺寸随新模型外界尺寸作微调，保持显示与轮径/轮宽定义一致；没有改动接触求解规则或重置旧参数。
- 转换以 `.bbmodel` 为准。用户的导出 JSON 与 BB 文件元素排列不同，部分元素旋转表达也不同；BB 文件保留多轴旋转，适合现有自定义轮组网格，不直接交给原版有角度限制的方块 JSON 加载器。

## 操作

1. 手持 Create Copycat 接受的方块，普通右键轮子安装点，为该轮填充材料。生存模式消耗一个方块，创造模式不扣除。
2. 同种方块再次右键：若材料有方向/轴等可调整状态，则循环调整，不再消耗材料。无可调整状态时保持原样。
3. 普通扳手右键：优先取回已填材料，并恢复 Copycat 默认外观。生存模式返还原来的一个物品，背包满时按原版库存逻辑放出。
4. 潜行扳手仍打开轮子参数；主手扳手、副手传送带仍优先打开履带参数。想取回材料时副手不要拿传送带。
5. 更换材料先取回再填入；每个轮子独立设置，不自动把一个材料复制到整组。

破坏轮子时，生存模式按常规方块掉落规则额外放出填入材料；创造破坏不额外返还。方块状态更新不会返还，移动标志下的方块移除也不返还。材料状态和原物品一起保存、同步；旧轮子缺少这些字段时自动使用 Copycat 默认材质。Create 原理图材料需求接口计入填入的材料。

填充会替换网格中 `copycat_base` 对应的面，不覆盖轮胎 `rx`、固定带面 `belt` 或程序生成的悬挂杆。悬挂杆由原白色改为 Create 基础纹理。自定义轮子的形状继续使用本项目模型，不变成填入方块的形状。

## 与 Create 对照

本轮查看本机 `libs/create-6.0.10.jar` 中 `CopycatBlock`、`CopycatBlockEntity` 的实际实现，直接调用其材料接纳函数，沿用 Create 的 allow/deny 标签、方块形状检查及初始朝向规则。物品消耗、同类材料调整、扳手返还和移动时不掉材料按同样交互设计接入独立的动力轮方块实体。

渲染按填入方块的烘焙模型取得各方向纹理、纹理旋转、染色及渲染层，支持常规方块的不同面纹理与透明层；资源重载会清理缓存。复杂模组依赖邻居/方块实体的动态模型和连接纹理尚未逐个兼容，不宣称等同于 Create 所有特殊 Copycat 渲染分支。

本轮是外观材料填充：材料不替换轮组的物理质量、摩擦、碰撞、红石功能或其他原方块行为。这些仍由轮组设置控制。
