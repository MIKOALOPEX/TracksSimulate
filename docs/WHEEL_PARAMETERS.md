# 0.4.0 负重轮参数与轮组配置

> 0.5.3 更新：三种轮子均可独立放置、潜行扳手配置尺寸；轮宽倍率默认同步所有轮种，轮径倍率单独选择同步范围。以下旧版整组说明由 [本轮操作说明](WHEEL_AND_BELT_UPDATE.md) 替代。

在负重轮的**原安装轴位置**潜行使用 Create 扳手。面板分为“悬挂承载 / 尺寸与偏移 / 显示”，悬停输入框可查看说明。切换页面不会丢失输入，点击“保存”一次提交三页设置；关闭不保存。

范围默认“当前负重轮”。切换为“同环负重轮”后，保存会把**全部三页参数**复制到同一履带的所有负重轮，覆盖各轮原有差异；导轮和托带轮保持原状。未连接履带时不能选整组。服务端先检查整环加载、归属、编辑权限、共面和路径范围，再修改成员；拒绝时保持界面与输入，悬停“保存”查看完整原因。

## 悬挂承载

位置以**偏移后的悬挂基准**为零，沿车体自身的 Y 负方向向下为正。默认偏移为零时，基准就是安装轴中心。这里的“车体坐标”不是玩家视角，也不是倾斜车辆所在世界的竖直方向。

| 参数 | 默认 / 范围 | 含义 |
| --- | --- | --- |
| 压缩端 | 0 格 | 轮心最小下降量，数值越小越靠近基准；不得小于 0 |
| 伸长端 | 1 格 | 最大下降量，最多 4 格；与压缩端至少相差 0.01 格 |
| 自然位置 | 0.5 格 | 弹簧的目标位置，必须位于两端之间 |
| 约束刚度 | 100 / 0–10000 | 恢复强度；越大通常越难压缩。使用 Sable 位置电机系数，不是 N/m |
| 约束阻尼 | 20 / 0–1000 | 抑制伸缩速度和弹跳，过大会减慢响应；不是 N·s/m |
| 单轮质量 | 100 / 1–10000 | 此枚独立移动轮体的质量，使用 Sable 质量约定；不是整条履带或整辆车的质量 |
| 悬挂开关 | 开启 | 关闭后锁定伸缩，保留配置位置处的固定原生轮体碰撞；Y 轴轮始终固定 |

例：压缩端 0.2、伸长端 1.2、自然位置 0.7，表示轮心的名义下降区间为 0.2–1.2 格。悬空轮仍受自身重力，所以它一般不会恰好停在自然位置。载荷大、弹簧弱时可能落到伸长端；受压车体可能压到压缩端。两端用物理解算约束，有微小数值误差，不是把模型坐标裁剪到区间。

面板原来的“轮组质量”已改名“单轮质量”，避免误以为它设置整条履带的总质量。

## 尺寸与偏移

| 参数 | 默认 / 范围 | 实际作用 |
| --- | --- | --- |
| 轮径倍率 | 1 / 0.25–3 | 同时缩放模型径向、原生盒体径向和绕带半径；同带速下大轮显示转得更慢 |
| 轮宽倍率 | 1 / 0.25–3 | 同时缩放模型轴向和原生盒体宽度；带宽仍取整环最窄轮宽的 85% |
| 平面横向偏移 | 0 / -4–4 格 | 沿轮轴平面横向移动悬挂基准及整个轮体 |
| 平面纵向偏移 | 0 / -4–4 格 | 沿轮轴平面纵向移动基准；不会改变悬挂行程的长度 |
| 沿轮轴偏移 | 0 / -4–4 格 | 沿轮轴移动整个轮体，已连接履带要求所有轮心保持共面 |

正方向固定如下，负值反向：

| 轮轴 | 横向 | 纵向 | 沿轴 |
| --- | --- | --- | --- |
| X | +Z | +Y | +X |
| Z | +X | +Y | +Z |
| Y | +X | +Z | +Y |

轮径倍率 2 意味着直径和半径都变成两倍，不会把悬挂行程或单轮质量也自动改成两倍。轮宽倍率独立于轮径，方便制作宽负重轮。当前模型与接触形状共享尺寸，未提供“看起来大但碰撞小”的独立倍率。

位移不是纯渲染偏移：Sable 原生轮体、约束基准、轮模、黄色选择框和履带路径同步改变。连接支杆仍从原安装点连到当前轮心。隐藏后也能在原安装点打开设置。

本轮只有负重轮开放这些设置。若同环还有固定轴向位置的导轮或托带轮，整组负重轮沿轴移出它们的平面也会被拒绝；可使用平面内偏移，或拆带后重新安排安装位置。全由负重轮组成的履带可以整体沿轴移动，只要新轮心共面。允许轮体重叠，保留每个连接节点；修改后出现带面交叉时提示玩家，已确认包覆方向不自动翻转。

## 显示

“轮体显示”和“连接支杆显示”分别开关。隐藏仅影响画面，**不移除质量、碰撞、悬挂或履带连接**。即使隐藏的是履带控制轮，整条履带仍然渲染。持传送带选择时，隐藏轮的黄色选框仍可见，便于定位。

隐藏与关闭悬挂含义不同：隐藏保留原来运动；关闭悬挂把轮体固定在偏移后的基准位置。参数、显示开关和缩放会随存档保存，旧存档默认倍率 1、偏移 0、显示开启。

## Gearwork 分组对照与后续接入

依据本机参考 JAR 的 `WheelMountBlockEntity` / `TrackMountBlockEntity` 参数定义和语言资源整理，只参考功能分类，没有复制其实现。Gearwork 的轮子与整条履带参数并不完全相同，不能把它们混成一套具有相同物理含义的常数。

| 分组 | Gearwork 中对应的功能 | 我们的落实方式 |
| --- | --- | --- |
| 身份与预设 | 设备名、轮胎/履带规格、硬度预设 | 本轮保留用户模型；后续增加命名、预设和复制工具，预设必须能展开成明确参数 |
| 几何与偏移 | 半径、宽度、前后/沿轴/竖直偏移 | **本轮已实现负重轮物理缩放和三向偏移** |
| 悬挂 | 自然行程、目标压缩比例、支撑权重、阻尼比例 | 已有自然位置、两端限位、刚度、阻尼和独立轮体质量；支撑权重不能直接当作额外支撑力，否则会与原生接触重复 |
| 显示 | 模型变体、隐藏局部结构等 | **本轮已实现轮体/支杆独立隐藏**；后续可开放材质及模型局部变体 |
| 驱动与制动 | 自由转动、刹车、驱动力增益、目标带速、最大带加速度 | 待接入带速和真实接触牵引后开放：驱动模式、传动比、扭矩上限、制动力、自由滚动、转向差速 |
| 抓地与滑移 | 纵向/横向/刹车抓地、转向刮擦、滚阻、被动纵向阻尼和滑移限制 | 待圆轮/带面接触求解接入后开放。应区分接触摩擦、履带内部损耗和驱动限制；当前盒体 API 未提供这些独立旋钮 |
| 接触采样 | 等效表面、接触采样设置 | 未来对应两点带段长度、带厚、接触预算和接触层；不能照搬射线采样数量来代表实体带面碰撞 |
| 履带几何与张紧 | 履带行、可视预测及相关参数 | 计划加入带宽/带厚、节距、名义总长、预紧、松弛和张紧器行程；可视预测应与实际力学设置分开 |
| 状态诊断 | 接地、压缩、载荷、滑移、地速、接触比例和混合调参状态 | 当前普通扳手可看物理状态与下降量；后续面板增加每轮载荷、端点触发、带速/地速、驱动冲突及接触段显示 |
| 破坏与维修 | 我们额外需要的 CBC 带段判定 | 待接入命中接口，增加带段耐久、断带阈值、失效状态和维修材料；不把“隐藏”当作损坏 |

本轮的整组编辑范围明确为“同一条闭合履带内的负重轮”。后续整车左右履带联动、按编号分组、导轮和托带轮配置需另行实现。

## 手动验收与当前限制

1. 开启游戏后确认三个页面文字清晰、切页保留输入、悬停有说明；输入非法端点或倍率应保留界面并显示原因。
2. 单轮设置轮径 1.5、轮宽 0.75；确认模型、黄色框、带面绕行位置随之改变。在 Sable 车体上检查实际接地高度也变化。
3. 分别修改三个偏移，确认安装轴不搬走、轮体与支杆移动；连接履带后尝试单轮沿轴偏移，确认被拒绝且所有轮维持原设置。
4. 在纯负重轮履带上选同环范围，修改倍率和沿轴偏移，确认整组同步。混合导轮履带先以沿轴偏移 0 测试平面内位移。
5. 分别隐藏轮体/支杆，确认带面与承载保留；关闭悬挂，确认固定轮碰撞仍在所配位置。保存重进复查参数。

物理碰撞仍是**不随视觉自转的盒体**，本轮不会实现圆轮滚动、牵引、带面承载或断履。静态世界与玩家交互仍沿用原安装格方块形状；缩放后的独立接触体作用于 Sable 物理解算，不代表玩家可以站在任意偏移轮面上。Sable 车体整体缩放仍不支持，本轮只支持轮体自身缩放。

已离线构建；68 项路径、35 项悬挂、34 项尺寸/布局检查通过。对本地 Sable 2.0.0 和 2.0.5 各执行 24 项独立原生物理检查，包括三种轴向的固定轮偏移、缩放后接地高度、弹簧与限位。未启动 Minecraft，GUI、整组保存、存档和游戏内集成仍需上述手动测试。
