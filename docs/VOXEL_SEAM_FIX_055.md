## 修改

旧规则先选 OBB 分离轴测试中的最小穿透方向，再检查这个方向是否指向被邻居遮挡的方块面。过滤只识别接近 X/Y/Z 轴的法向，漏掉斜向边缘法向；此外，选到隐藏面后直接丢弃整个接触，也可能漏掉有效地面支撑。

现在对完整碰撞方块先计算六个外露面。所有分离轴仍参与“是否碰到”的检测，但选择接触响应方向时排除被邻居遮挡的面，以及指向这些面的斜向边缘法向。若隐藏方向被排除，会继续选择有效的外表面法向，而不是丢弃整个接触。

适用于主世界与其他 Sable 车体的完整方块碰撞，外露面掩码随障碍物局部坐标处理。非完整方块暂沿用原 OBB 判定，不宣称已经解决所有台阶/复杂形状的接缝。

没有修改用户轮组参数、合并非固定载荷质量、锁定车体姿态或直接覆盖车体速度。

## 日志扩展

位置仍为 `test-environment/combined/logs/trackssimulate-physics.log`，版本字段 `0.5.5`，保留约 20 MiB 轮转限制。

- `event=mass_change`：车体质量或局部质心变化时立即记录。
- `mass_delta` / `peak_mass_delta`：当前子步质量变化 / 窗口最大绝对变化。
- `local_com` / `local_com_shift` / `peak_com_shift`：局部质心及其变化，区别于车体在世界中的正常移动。
- `inverse_inertia_local`：局部逆惯量张量六个独立元素，顺序为 xx、yy、zz、xy、xz、yz。
- `peak_spring_speed`：窗口内悬挂内部坐标速度绝对值峰值。
- `dynamic_loaded_contacts` / `max_contact_body_mass`：履带直接接触其他物理体的有载接触数 / 这些物理体的最大质量。
- `strongest.obstacle`、`voxel`、`obstacle_body`、`obstacle_mass`、`exposed_mask`：最大法向冲量的接触对象类型、方块坐标、物理体标识、质量、外露面掩码。掩码位为 +X=1、-X=2、+Y=4、-Y=8、+Z=16、-Z=32；主世界完整平地内部顶层方块通常为 4。

仅放在车上、没有直接碰到履带的物理体，不会出现在 `dynamic_loaded_contacts` 中；其通过原生碰撞施加给车体的作用仍体现于既有 `peak_external_dv/dw`。这些字段也包含重力、其他原生约束及模组作用，不能直接视为某个载荷的专属冲量。
