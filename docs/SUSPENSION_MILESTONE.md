## 手动测试

继续使用 `D:\CreateAdd\Start_TracksSimulate_Client.bat`，会编译当前源码并启动 combined 环境，准备失败时按原有逻辑离线重试。无需拷贝 JAR。

1. 先在静态世界制作简单车架，左右各放两枚轴向 X 或 Z 的负重轮。轮子仍通过右键 Create shaft 安装。不要用导轮/托带轮代替负重轮验证悬挂。
2. 在负重轮的**原安装轴位置**潜行使用 Create 扳手，打开“负重轮 · 悬挂设置”。保存参数；普通扳手查看状态和轮心下降量。交互目标仍在安装格，移动轮体目前未接入独立拾取。
3. 用环境现有装配工具将车架装配为 Sable 车体，并解除固定。静态世界不创建悬挂刚体，轮子仍处于安装位置。
4. 在平地观察轮心向下伸出、车体落地后悬挂压缩。白色伸缩杆标明安装点和移动轮心的关系。先检查无履带的独立负重轮，再用传送带闭环：带面应随轮心移动，内外包覆方向不突然翻转。
5. 给车架逐步加负载，比较压缩量；支起车体让轮子悬空，比较自然位置与伸长端。可暂将刚度和阻尼都设为 0，单独观察重力作用下的伸长端限位。
6. 将两枚负重轮布置为轮体重叠，确认不会因同车轮体碰撞相互弹开；再拆除、关闭悬挂、卸载车体或退出重进，检查没有残留承载。重进会重新建立原生对象，恢复上次记录的行程位置，但不恢复轮体的独立瞬时速度。
7. 保存退出后检查参数和履带包覆方向。旧存档缺少参数时使用默认值；旧履带首次恢复会规划并保存明确的包覆方向。

## 参数

距离单位为格，以偏移后的悬挂基准为零（默认就是安装轴中心），沿**车体局部 Y 负方向**向下为正。车体倾斜时悬挂轴一起倾斜。

| 参数 | 默认 | 含义与范围 |
| --- | --- | --- |
| 压缩端位置 | 0 | 最小下降量，不能小于 0 |
| 伸长端位置 | 1 | 最大下降量，不能超过 4；总行程至少 0.01 |
| 自然位置 | 0.5 | 弹簧目标位置，必须位于两端之间 |
| 约束刚度 | 100 | Sable 原生位置电机系数，0–10000 |
| 约束阻尼 | 20 | Sable 原生位置电机系数，0–1000 |
| 轮组质量 | 100 | 独立移动盒体质量，1–10000，使用 Sable 的质量约定 |
| 悬挂开关 | 开启 | 关闭时锁定伸缩，保留配置位置处的固定原生轮碰撞 |

例如压缩端 0.2、伸长端 1.2、自然位置 0.7：轮心向下的名义运动区间是 0.2–1.2 格。自然位置不等于悬空时的实际平衡位置，轮体自身重力仍会使其下沉。两端为求解器约束，不是渲染坐标截断；离散求解存在微小误差，极端冲击下也不能声称绝对零穿透。

刚度/阻尼沿用原生电机的系数定义，**不是直接标定的 N/m 与 N·s/m**。增加车体负载后可提高刚度以减小压缩；不要把原型参数当作最终材料规格。

## 实现与边界

- 每个负重轮有一个独立 `BoxPhysicsObject`，以缩放后的轮半径和半宽作为盒体尺寸。水平轮轴且开启悬挂时，相对车体锁定横向和角向自由度，只允许局部 Y 方向移动；其它情况全部锁定在配置位置。盒体角部比圆轮更突出，旋转显示尚不参与碰撞求解，不能据此评价最终滚动、摩擦或越障性能。
- 单轴约束的 Y 限位为 `[-伸长端, -压缩端]`，目标为 `-自然位置`。接触冲量由原生求解器通过约束传回车体，没有额外射线支撑力，也不每帧传送轮体。
- 安装方块在 Sable 中只保留小型固定安装座碰撞，避免原位置的整轮碰撞重复承载。安装座的方块质量仍属于车体，移动轮组质量属于独立盒体。
- 关闭轮体与自己车体、同车负重轮之间的接触，保留对地面及其他物理对象的接触。同车轮对采用无锁轴约束排除接触；本轮每个车体最多 64 个负重轮物理对象，轮对数量随轮数平方增长。仍有每环 32 轮的装配上限。
- 竖直 Y 轴轮组保持固定轮行为，不启动悬挂；缩放车体暂不支持，扳手显示原因。创建失败会停止该轮重试并记录日志，可通过重新保存参数或重载重试。
- 框选与预览使用实际轮心，闭合后保存各轮包覆方向。悬挂运动仅更新切线与圆弧，不重新搜索拓扑；新点选仍按原有规则每次规划不交叉路径。带长随轮心改变，尚无张紧器、松弛或长度守恒；运动后的交叉不触发自动换侧。
- 参数写入存档；位移由服务端同步并在客户端插值。移除方块、区块卸载、车体移除和世界关闭均清理约束/刚体；同一个盒体的重复卸载回调做幂等处理。观察者在服务器 tick 前登记，避免在 Sable 遍历观察者时修改集合。
- 导轮/托带轮的固定碰撞、玩家的安装格碰撞沿用前版。**带面碰撞与承载、圆轮滚动、动力推进、零导轮自由滚动、炮击断履仍未实现。** 原生盒体也尚未接入玩家实体站立和炮弹命中接口。

Sable API 按本地 2.0.0 JAR 编译；坐标约定、位置电机和盒体接口另与官方固定版本的 [joints.rs](https://github.com/ryanhcode/sable/blob/mc1.21.1-2.0.0-neoforge/sable_rapier/src/main/rust/rapier/src/joints.rs) 和 [boxes.rs](https://github.com/ryanhcode/sable/blob/mc1.21.1-2.0.0-neoforge/sable_rapier/src/main/rust/rapier/src/boxes.rs) 核对。没有复制参考轮组模组实现。

## 已执行验证

`scripts/gradle.ps1 build --offline --console=plain`：68 项几何检查、35 项悬挂参数及 34 项尺寸/布局检查通过，产物为 `build/libs/trackssimulate-0.4.0-prototype.jar`。几何检查包括前版选点回归以及悬挂平移、反包覆保持、保存方向恢复；参数检查包括端点顺序、符号、范围与非有限数值。

`python scripts/check_native_suspension.py`：仅从本地 2.0.0 与 2.0.5 JAR 提取 Windows 物理库，在独立 128 MB Java 进程调用 JNI，**不启动 Minecraft、世界或游戏服务器**。两版各 24 项检查通过，覆盖弹簧沉降、两端限位、盒体接地、同车轮体接触排除、接触力传递至动态车架及先移除车架再清理约束。

固定安装点 Y=4、行程 0–1、默认弹簧的检查结果（两版一致）：自然下沉后的轮心 Y=3.40190，伸长端 Y=2.99999，压缩端 Y=4.00001；障碍顶面 Y=3 时，半高 0.59 的轮体停在 Y=3.58703。

这些检查覆盖底层约束机制，不等于完整游戏集成验证。参数界面、Sable 装配/拆分/合并、多人同步、大规模帧率及世界卸载表现尚未启动实测。测试桥接类仅在 `src/nativeChecks`，不加入 Gradle 主源码或产物，也不包含在游戏运行类路径中。
