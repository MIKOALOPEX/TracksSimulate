# 0.5.3：独立放置、摩擦与尺寸配置

2026-10-04。无需拆除旧轮组。使用 `D:\CreateAdd\Start_TracksSimulate_Client.bat` 编译当前源码并自行启动。

## 放置和操作

- 导轮、负重轮、托带轮都是可直接放置的方块，不再要求先放 Create shaft。轮轴垂直于点击面：点击墙面得到水平轴，点击顶/底面得到 Y 轴。正常方块放置沿用 Minecraft 的权限、碰撞和物品消耗检查。
- 保留对未浸水 shaft 的原位转换，继承 shaft 轴向。直接放置的导轮默认全轴透传，半轴默认连接朝向放置面。
- 潜行使用 Create 扳手点击任意轮子的原安装点，打开统一轮子设置。默认进入“尺寸/偏移”；隐藏或偏移后的轮子仍从原安装点编辑。
- 导轮的半轴/全轴开关移到“显示/轴”页，保存后生效；半轴仍通过普通扳手点击轴端选择输入侧。负重轮保留悬挂页，另外两种轮不启用悬挂。
- 点击“履带”进入整环物理设置，关闭后返回轮子设置，保留尚未保存的轮子输入。原来的“主手扳手 + 副手传送带”快捷入口仍有效。

## 尺寸同步

| 参数 | 范围 | 应用方式 |
| --- | --- | --- |
| 轮宽倍率 | 0.25–3 | 保存轮子设置时同步同一条履带的所有轮，包括导轮、负重轮和托带轮；未连接时仅当前轮 |
| 轮径倍率 | 0.25–3 | 默认仅当前轮；尺寸页切换“轮径：同步所有轮”后覆盖整环轮径倍率 |
| 带宽倍率 | 0.25–3 | 履带页独立设置，带宽 = 整环最窄轮实际宽度 × 0.85 × 带宽倍率 |
| 带面厚度 | 0.02–0.25 格 | 履带页设置，渲染和接触判定同时生效 |

轮子倍率以各自原始模型为基准；同步同一倍率并不把导轮和小托带轮变为同样的实际直径/宽度。轮径变化会重新计算履带路径，沿用已保存包覆方向和负重轮下部承托规则。履带长度随路径变化，仍未模拟定长张力。

轮径同步不会覆盖其他轮的偏移、显示或悬挂参数。“悬挂等：同环负重轮”是独立范围，仅同步负重轮的悬挂、偏移和显示。所有成员、权限、共面和路径检查在修改前完成，拒绝非法参数时不先改一部分。

轮体模型和负重轮原生碰撞体使用新尺寸；已连接履带的接触带段也使用新轮径/带宽。导轮和托带轮独立刚体碰撞仍沿用既有实现，尚未增加与缩放模型完全一致的独立轮体碰撞；原安装点的方块选取框保持不变。

## 摩擦与打滑

履带页第一项“摩擦系数”从 0–2 扩大为 **0–10**，默认仍为 0.8，不擅自覆盖存档中的已有数值。可逐步调高并保存整环，对比同样 RPM、载重、地面下的打滑。纵向牵引和横向防滑共享 `摩擦系数 × 实际接触法向冲量` 上限。

提高摩擦能增加有载接触的牵引上限，不会给离地履带凭空提供牵引；驱动力或目标带速过大、履带未接地也不能只靠摩擦参数解决。旧存档缺少带宽字段时按倍率 1 读取，已有摩擦/动力/厚度参数保留。
