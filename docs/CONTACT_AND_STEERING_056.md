# 0.5.6：接触范围、多履带与差速转向

2026-10-04。本轮交付包含设置界面、服务端校验、存档、物理计算、判定框显示与诊断日志。助手未启动游戏；整车、坡面、载荷及重力法杖场景由用户测试。

## 实测依据

0.5.5 日志中，质量 36 的反向驱动车体在 13:50:59（北京时间）出现单窗口履带接触速度变化峰值 17.631092，外部变化约 0.055459。此前按带长计算的虚拟带质量可以远大于整车，固定 30000 的每环驱动力也不随整车质量或履带数量调整。不能把这种异常简单归为横向摩擦太大。

开发中途的 0.5.6 日志在 18:07:59–18:08:09 记录质量 30、两侧横向摩擦 1.8/1.0、反向目标带速时，平均带速约 0.02467；18:08:30–18:08:41，两侧改为 1.0 后约为 1.17397。这与用户报告的停转吻合。该中途版没有侧滑过渡模型，动力加速度预算默认 12。最终版增加过渡模型，并将新默认预算改为 30。

中途日志也仍存在高速度和外部求解变化，例如质量 36、摩擦 10 阶段的外部速度变化峰值约 61.50。外部字段包含原生碰撞、工具、其他约束及模组作用；不能据此认定某一项是原因，也不宣称本轮已经解决所有游戏内弹飞。读取结果保存于 `build/physics-056-interim-analysis.json`。

## 物理行为

- **安装点与承载分开**：已连接履带的轮子、由独立轮体处理碰撞的负重轮，不再在 Sable 车体上附加固定安装点碰撞。安装点仍可被玩家选中和配置。其他车体的履带碰撞查询也遵守同一 Sable 自定义形状，避免再次读回安装点的普通方块盒。
- **接触范围可见且可配置**：带段依旧使用两点之间的有向盒。径向扩张改变厚度方向的实际碰撞范围，侧向扩张改变轴向范围；预测距离只允许提前处理即将接触的间隙，不等于悬空支撑。蓝色线框复用物理盒构造和分段规则，包含扩张、不包含预测查询外壳；悬挂显示采用客户端插值。
- **共享整车预算**：所有有效履带环共同求解，不假设只有左右两条。每环带质量为 `整车质量 / 环数 × 惯量占比`；每环驱动力取 `驱动力上限` 和 `整车质量 / 环数 × 驱动加速度上限` 的较小值。添加相同设置的环不会把总惯量及加速度预算成倍放大。各环可有不同预算；总力仍受各环份额约束。
- **质量变化**：等效带质量增加时降低对应带速，避免凭空增加已有旋转动能；减少时不自动加速带子。非固定载荷没有并入车体质量，预算采用 Sable 报告的车体质量，载荷作用仍经实际接触传递。
- **有限横向剪切响应**：“横向摩擦系数”决定抓地上限；“侧滑过渡速度”决定低滑速下横向阻力达到上限的快慢。后者大于 0 时使用隐式阻尼，不再强行把每个带段的侧滑都压到零。它适用于两环、多环、水平环及侧面接触，不依赖识别哪条是左履带，也不会直接添加车体转向力矩。
- **柔性法向接触**：接触柔度使相互矛盾的接触反力有有限解；穿透恢复速度单独限制修正速度。摩擦继续受法向压力及纵横向联合摩擦椭圆约束。侧面抓地按接触法向与轮轴夹角连续调整，保留侧面碰撞。

低速横向关系在未达到摩擦上限时近似为 `侧向冲量 = -横向摩擦上限 × 接触后侧滑速度 / 侧滑过渡速度`，由求解器隐式计算，不是把计算出的力再直接施加一次。该模型是连续带接触的近似；调大过渡速度会降低转向刮擦阻力，也会增加受持续侧向力时的缓慢侧移。设为 0 可对照原先的静摩擦模型。

## 完整履带参数

潜行使用 Create 扳手点轮子的安装点，在轮子设置中进入“履带”；也可主手扳手、副手传送带右键打开。三个页签均保存到整环。轮组的尺寸、偏移、显示与悬挂行程仍在轮子界面。

| 页签 | 参数 | 默认值 / 范围 | 作用 |
| --- | --- | --- | --- |
| 抓地/侧面 | 纵向摩擦系数 | 1.2 / 0–10 | 纵向接触抓地上限 |
| 抓地/侧面 | 横向摩擦系数 | 1.8 / 0–10 | 侧滑接触抓地上限，区别于悬挂阻尼 |
| 抓地/侧面 | 侧面抓地倍率 | 0.5 / 0–1 | 轴向侧面碰撞的抓地相对踏面倍率 |
| 抓地/侧面 | 侧滑过渡速度 | 0.15 / 0–2 格/秒 | 低速横向剪切响应；0 恢复静摩擦对照 |
| 动力/惯量 | 驱动力上限 | 30000 / 0–200000 | 每环绝对力上限，仍受质量预算限制 |
| 动力/惯量 | 动力限速 | 8 / 0.1–16 格/秒 | 目标带速上限，非车速锁定 |
| 动力/惯量 | 滚动阻力 | 10 / 0–1000 | 带速耗散力，0 便于自由滚动对照 |
| 动力/惯量 | 刹车强度 | 0 / 0–1 | 制动力份额，上限随质量预算分配 |
| 动力/惯量 | 驱动加速度上限 | 30 / 0.1–200 格/秒² | 质量归一化动力预算；过低可能没有足够力矩原地转向 |
| 动力/惯量 | 惯量占比 | 0.05 / 0.005–1 | 等效带惯量占整车质量的分配比例 |
| 接触/判定框 | 带面厚度 | 0.08 / 0.02–0.25 格 | 显示厚度及基础碰撞厚度 |
| 接触/判定框 | 带宽倍率 | 1 / 0.25–3 | 相对最窄轮宽 85% 的带宽倍率 |
| 接触/判定框 | 径向接触扩张 | 0.025 / 0–0.5 格 | 厚度方向两侧各增加的碰撞距离 |
| 接触/判定框 | 侧向接触扩张 | 0 / 0–0.5 格 | 轮轴两侧各增加的碰撞距离 |
| 接触/判定框 | 预测距离上限 | 0.15 / 0.005–0.5 格 | 随点速度计算的预测查询距离上限 |
| 接触/判定框 | 接触柔度 | 0.1 / 0.001–1 | 越大法向约束越柔，不是弹簧刚度 |
| 接触/判定框 | 穿透恢复速度 | 0.12 / 0–1 格/秒 | 最大穿透修正速度，0 关闭位置恢复作对照 |
| 接触/判定框 | 显示接触判定框 | 隐藏 / 显示、隐藏 | 蓝色实际接触盒，需保存后生效 |

摩擦及预算大并不保证任何形状都能转动或爬坡。纵向抓地仍需足够法向压力，原地转向仍需克服刮擦力矩；高抓地也会传递真实倾翻力矩。通过实际动力冲量、滑移和摩擦占用判断，不再仅凭带速为零把它归为动力冲突。

## 旧存档与中途版

已有参数保留；缺少的参数读取上述默认值。不覆盖用户修改过的摩擦、尺寸或悬挂。用户已运行过中途版，其 `MaxAcceleration=12` 可能已写入存档，最终版不会擅自将它重置。

**对需要测试最终默认行为的每条履带，打开“动力/惯量”页点“本页默认”，再打开“抓地/侧面”页点“本页默认”，最后点“保存整环”。** 这样使用加速度预算 30、横向摩擦 1.8、侧滑过渡速度 0.15；轮子尺寸、悬挂和接触范围不受这两页重置影响。若保留自定义动力或摩擦，可只修改对应字段。多条独立环分别保存。

重新启动客户端才能加载最终代码。仍用 `D:\CreateAdd\Start_TracksSimulate_Client.bat`，无需复制 JAR。网络参数协议已更新，联机双方必须使用相同最终版本。

## 日志

`test-environment/combined/logs/trackssimulate-physics.log`，及 `.1`–`.3`，总计约 20 MiB。最终记录同时包含 `version=0.5.6 contact_model=soft_shear_v1`，可与中途版同为 0.5.6 的日志区分。

新增/关键字段：

- `active_loops`、`belt_mass`、`effective_drive_force`：环数、等效带质量、实际每环驱动力限额。
- `max_acceleration`、`inertia_ratio`：解释实际分配依据。
- `limited_target`、`motor_J`、`drag_J`、`speed_before_contacts`、`speed`：限速后的目标、电机/阻力施加的带冲量、接触前后带速；用于定位停转发生在哪一步。
- `lateral_slip_speed`、`max_side_utilization`、`max_side_slip`：侧滑模型参数、采样步最大横向摩擦占用、剩余侧滑。与 `mu_side`、`strongest.grip_scale` 一起看；占用率不是转向成功率。
- `contact_offset`、`side_offset`、`prediction_distance`、`side_grip`、`softness`、`recovery_speed`：实际使用的接触设置。
- `belt_kinetic_energy`：接触后等效带动能，不是整车总能量。
- 继续记录车体质量/质心/惯量、速度角速度、履带冲量/力矩、穿透、外部变化、最强接触对象及悬挂行程/速度。

`contact_v_after/w_after` 是履带求解器预测结果；后续 Sable 原生求解器和其他模组仍可能改变车体状态。`peak_external_dv/dw` 是到下一个采样步之前的差异，不应当直接当作某个物理体的专属作用。

## 本阶段验收矩阵

以下为交给用户的实机场景，不是助手已完成的测试。保持同一存档，依次比较，便于定位日志时段。

| 场景 | 观察与对照 |
| --- | --- |
| 普通双履带平地，低/高质量 | 直行、松动力、制动；观察弹跳、带速和整体漂移 |
| 双流原地转向 | 两侧反向，先最终默认，再单独改变横向摩擦或过渡速度；观察停转和升空 |
| 3、4、8 条环 | 同向、部分反向、部分无动力；检查共享动力与接触，不假设两条成对 |
| 水平环、整车侧躺 | 带侧面触地、侧面撞墙；保留碰撞，观察瞬时冲量和弹飞 |
| 上坡及坡脚 | 开蓝色框观察带面和安装点；改变径向扩张，确认实际盒先接触、安装点不额外卡住 |
| 重力法杖抓取 | 抓取、落地、释放；比较履带自身变化与外部变化 |
| 非固定载荷、装卸和质量突变 | 平地及原地转向，记录质量变化事件，检查载荷与车体抖动 |
| 保存、重进和参数修改 | 检查三个页签设置、判定框、旧连接及存档仍有效 |

本阶段仍采用连续带和内部悬挂坐标，未完成链节张力、松弛、脱轨、CBC 炮击断履；不把这些规划功能描述为已有测试能力。完整车体缩放亦未开放，轮子/带宽尺寸配置可用。参考 Gearwork 的参数组织能力，不复制其 ARR 实现。
