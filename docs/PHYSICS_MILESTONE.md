## 启动与操作

继续双击 `D:\CreateAdd\Start_TracksSimulate_Client.bat`。它会编译当前源码并启动 combined 环境；联网准备失败时自动离线重试。无需复制 JAR。`dist/` 里的旧压缩包未更新。

- 轮子设置：副手不持传送带，在负重轮**原安装轴**处潜行使用 Create 扳手。保留悬挂、尺寸/偏移、显示三页和同环负重轮整组保存。
- 履带物理设置：**主手 Create 扳手 + 副手 Create 传送带**，右键任一已闭合轮的原安装轴。不需要潜行，导轮/托带轮也可打开，适用于没有负重轮或没有导轮的环。
- 普通扳手点击负重轮可查看悬挂位置，以及整环带速、接触数量和接触反力。面板中的运行状态是打开时的快照。
- 轮组必须装配为 Sable 车体并解除固定，才会进行承载与行驶。静态世界保留动力旋转预览。

## 本轮实现

1. 两点带段接触：轮间直段和绕轮圆弧被划分为有宽度、有厚度的有向盒体。与方块碰撞形状检测，覆盖底部、前后、上方和侧面，不局限于向下射线。相邻带段端盖不作为独立台阶阻挡。
2. 实际反力：接触求解产生线冲量和角冲量，写入 Sable 刚体。轮间反力按端点权重传递；负重轮悬挂方向的分量进入独立轮毂，剩余分量及力矩传给车体。导轮、托带轮处的带面直接把力传到车体，没有额外弹簧。
3. 动力与摩擦：导轮 Create RPM 换算为目标带速，电机驱动力有上限。纵向推进和横向防滑共享 `抓地系数 × 接触反力` 的限制，不因分段增多而成倍增强。悬空可转带，但不会因此获得车体推进力。
4. 自由滚动与刹车：没有动力源、甚至整环没有导轮时，地面相对运动也能带动带子。滚阻与刹车作用于共享带速，再经接地摩擦影响车体。多个导轮要求不一致的带速时，进入冲突制动并显示状态。
5. 对其它 Sable 车体的方块接触施加等大反向冲量。此项已接入，复杂多车接触仍需游戏内验证。
6. 参数网络校验、整环保存和 NBT 持久化。支持既有轮体缩放、偏移和隐藏；隐藏不取消承载。

闭环负重轮的独立原生盒体缩为内部轮毂，外侧由带面承载，减少原先方盒四角在圆弧之外重复支撑的问题。拆带后恢复独立负重轮盒体。异常会暂停该环带面求解、显示原因并恢复可用负重轮的盒形承载；保存履带参数可重试。它不是故障情况下保证车体不下落的机制。

## 新增整环参数

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| 抓地系数 | 0.8 | 0–2，统一控制纵向和侧向摩擦；0 可测试打滑 |
| 驱动力上限 | 30000 | 0–200000，引擎力单位，整条履带电机的最大驱动力，不是每段各施加一次 |
| 动力限速 | 8 格/秒 | 0.1–16，限制电机目标带速；不强行截断车体速度或外力滚动速度 |
| 滚动阻力 | 10 | 0–1000，阻碍带速的恒定力；测试无动力滑行时可设 0 |
| 刹车强度 | 0 | 0–1，最大制动力为 200000 引擎力单位；1 用于停车测试，需有接地摩擦 |
| 带面厚度 | 0.08 格 | 0.02–0.25，渲染和接触厚度一起改变；围绕既定带面中心线对称增厚 |

实际带速取决于导轮转速、半径、动力上限、制动和接地负载。没有动力源可以自由滚动；仍接着一个目标为 0 RPM 的动力源时，则属于电机保持零速，两者不同。

悬挂参数继续按 [轮组参数说明](WHEEL_PARAMETERS.md) 配置：下降量沿车体局部 -Y，压缩端/伸长端是行程限制，自然位置是弹簧目标。质量和车架形状会影响平衡压缩量；满载即压到底时应增加刚度或调整质量/行程。以下测试可从刚度 1000、阻尼 40 试起，再和原默认 100/20 对比，不应把这一组数值当作所有车辆的最佳值。

## 一次集中测试的顺序

| 场景 | 操作 | 重点观察 |
| --- | --- | --- |
| 基础承载 | 简单车架、左右各一条对称履带，先保持无动力；平地解除固定 | 车体落地稳定，悬挂压缩、轮心随动；不是只有模型停在地面 |
| 正反行驶 | 每环先只用一个导轮，32 RPM 起步，再反转 | 接地推进、反向后倒车；两边前进方向要一致，镜像安装可能需要反转其中一路 |
| 动力离地 | 支起车体，让两条履带不接地 | 带子可转，车体不因带子空转自行加速 |
| 自由滚动 | 断开动力来源，滚阻 0、刹车 0，外力拖动；再换成没有导轮的闭环 | 带速由接触带动，停止外力后可滑行，不强行回零 |
| 制动/低抓地 | 滑行时刹车设 1；再对照抓地 0 和 0.8 | 有抓地时停车；抓地 0 时不能靠刹车阻止车体滑动 |
| 带段承载 | 小平台放在两轮之间的下部直段下方，轮子均不触碰平台；刹车 1 | 中间带面能传回支撑，悬挂受压，车体不直接掉下去 |
| 越障 | 低速接近薄台阶、逐渐增高，再试半砖和坡面 | 弧段与直段共同接触，没有分段端盖卡住；不预设所有整格墙都能爬越 |
| 转向 | 左右两环不同转速，再试一侧反转 | 摩擦造成真实偏航，同时允许侧滑；抓地越高越可能需要更大驱动力 |
| 异形与偏移 | 三角形、局部从下/侧穿过的既有布局，调整负重轮位置/大小 | 包覆方向不突然翻转，轮与带面随悬挂变化；交叉仍提示玩家 |
| 保存和拆卸 | 保存退出重进、拆带、拆轮、解除/重新装配 | 参数保留，无残留带面承载；故障提示和日志可定位问题 |

反馈可按“场景、轮组布局、RPM/参数、实际结果”汇总；如果有异常，同时保留 `test-environment/combined/logs/latest.log`。本轮没有要求逐项反馈后才能继续启动测试。

## 当前边界

- 这是带真实接触反力的简化连续履带模型。带面跟随轮心重建，**尚不守恒整环长度，也没有真实张力、松边下垂、链节质量分布、脱轨或断带**。带速采用等效滚动惯量：每格路径 20、最小 20，引擎质量单位；这不是额外加载到车体上的真实链节质量。
- 本轮带面查询世界方块和其它 Sable 车体方块的碰撞形状。未接入玩家/生物站立、实体拾取、CBC 炮弹命中判定；其它模组独立物理对象和其它移动履带的虚拟带面不在本轮查询范围。
- 原生轮毂是盒体，带面是离散接触段；不等同于精确圆柱和逐链节刚体。接触允许少量穿透；高速冲击或大时间步仍可能穿透，当前预测接触不是完整连续碰撞检测。
- 支持轮子自身缩放，不支持 Sable 车体整体缩放。X/Z 轴轮有悬挂，Y 轴轮仍固定。导轮/托带轮的包覆带面可接触并把力传给车体，但不新增主动悬挂。
- 当前 Create 应力需求仍为导轮固定原型值，没有按实际扭矩回写应力网络，也不向 Create 发电。多个导轮带速冲突时制动，不自动替玩家调整齿轮比。
- 每环最多 768 个物理带段、2048 个候选接触，单次查询预算 24000 格次，最多查询 16 个相邻车体；独立负重轮仍最多 64 个/车体。超限会暂停该环并提示，避免无界内存/运算开销。
